# Riverfall — meadow colour, exterior wall belt and wooded ridges

Task `river-slope-meadow-20261125` on `codex/character-continuity-pipeline`. The owner's annotated photo identified a yellow-lime foreground and a flat exterior slope. This change is confined to Riverfall rendering and its release allowlist. No lighting, road/house layout, collision, spawning, match code or earlier demo changed. The public game does not need additional art downloads.

- One shared procedural blade atlas with a cooler live-leaf range, occasional straw tips, lower emission and patch variation. The meadow starts again outside all four walls; the near band fades into larger irregular clumps anchored to the slope. Both terrain shaders supply a continuous understory beyond the blade belt, excluding the river. Mobile uses texture luminance rather than brown forest-floor RGB for this understory. The six ridge patches use layered green/blue-green upper slopes, broken rock, clustered crowns and dappled albedo.
- Deterministic checks: 10,955 exterior tufts (N 2,639; S 2,720; E 2,684; W 2,912), up to 39.84 m outward. Of 3,360 qualifying grid samples 0.9–12 m outside the perimeter, 3,244 (96.5%) have a root within 1.1 m. This is a spatial sample, not % covered pixels. No roots inside the screened river channel or off the height field. Existing wall-meadow, bank-screens, squads-opening, landscape-checks, afterrain-ground-checks and environment-polish-checks passed.
- Four fixed-camera frames per profile, captured from the running WebGL canvas offscreen. Desktop 26,855 tufts / 322,260 triangles; mobile profile 24,621 / 196,968, both four meadow batches. No reported page/console errors. Same-camera paired evidence and individual frames under `experiments/sunbreak-river-v4/qa/slope-meadow-20261125`. Actual phone frame pacing and alternative weather have not been measured.
- Model: Gateway requested and returned `claude-fable-5-2` for the plan, placement, shader/atlas work, QA test, tuning and independent review. Sanitized per-call results/usage/cost included with evidence; not independent proof of upstream billing. Reviewed against matched frames and existing gameplay exclusions. Visual gate `CONDITIONAL PASS` for this iteration: distant ground reads as uninterrupted cover, not individual blades; shadowed grass can look dark.
