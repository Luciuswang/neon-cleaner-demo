# Neon Cleaner 双周项目报告（2026-11-08 至 2026-11-21）

报告依据：`origin` 17 个远端分支的冻结快照、122 个去重提交、57 个工作日志事件，以及各分支对应的 handoff/QA 记录。统计截止：2026-11-21（Asia/Shanghai）。提交整合状态不等同于 QA 通过；未推送或离线工作不可由 GitHub 观察。

## Executive summary

本周期仓库有实质进展，重点集中在 MetaHuman/骑手连续性验证，以及 SUNBREAK/Riverfall 可玩场景的连续迭代。MetaHuman starter、用户绑定角色基线、皮夹克拟合候选、UE 5.9 MetaHuman reload/MCP 验证均已形成可追溯提交；Riverfall 从独立地图、战术交互和自动射击演示推进到雨后光照、石墙掩体、程序材质迁移与地表/植被细化。

当前结论仍是“工程与功能大部分通过，视觉/性能发布未通过”：Riverfall 的独立源代码、功能和采样美术检查多次 PASS 或 CONDITIONAL PASS，但严格性能样本仍失败，连续运动证据未完成，AAA/公开发布保持 BLOCKED。MetaHuman 皮夹克仍是未装配、未验证的候选；不要将其描述为已替换的最终骑手。

## Validation / QA evidence

- 远端证据范围：17 个分支、122 个去重提交、57 个工作日志事件；窗口内的整合与未整合提交均已纳入，不能只看 canonical branch。
- MetaHuman 方向：starter 创建和 reload/MCP 检查有工程验证；皮夹克候选只有 scratch import、权重/臂肘数值检查，缺少 assembled MetaHuman、视觉 fit、clipping、骑行和最终游戏测试。
- Riverfall：多项 CPU suite、原生浏览器功能阶段、来源审计和有限采样美术检查通过；部分任务标记为独立 art PASS 或 CONDITIONAL PASS。
- 严格门禁仍失败：多个 Riverfall 检查点报告 p95 约 35–36ms，max 约 66.7–339.1ms，存在超过 50ms 的帧；连续运动 review 未验证。部分流程明确标记 AAA/public release BLOCKED 或 REVISE。
- 证据完整性限制：两条历史 worklog 缺少带时区时间戳；另有 unidentified event 缺少 `event_id`/`machine_id`，已保留为 provenance 限制。

## Blockers / risks

- Riverfall 的严格帧时间/反射/层级绘制成本仍未隔离解决；需先处理 hitches，再做连续运动和公开发布判断。
- 下载资产和私有 UE 资源的许可、恢复和全项目可移植性仍需确认；当前本机 `ParagonPhase`/私有 vault 的未完成本地改动触发了同步脚本保护，属于本地 Epic/Fab 设置与保险库状态问题，不是项目工作缺失。
- 皮夹克不是最终骑手服装：官方 rig/texture assembly、fit/clipping、手臂与骑行姿态接触、实际游戏替换都未通过。
- 当前生产规则要求先验证 Fable 5.2 Gateway 路由；`river-reference-house` 在实现前暂停，不能因连接/认证/超时就推断余额耗尽并切换 Codex。
- 视觉结论仍需把源代码 PASS 与 sampled art PASS 分开；不能把静态截图、成功解码或单次端点测试替代连续动态接触和性能证据。
