## 人工编辑

1. 用 Blender 打开 `.blend`，或导入 `timber-house-source.glb`。
2. 按 `Foundation`、`Walls`、`Windows`、`Furniture`、`Ceiling` 等组修改。
   黑瓦已展开成独立网格；门为独立 `DoorPivot`，不可与墙体合并。
3. 材质使用金属度/粗糙度 PBR；保留 UV、材质贴图和对象名称。
   可修改贴图、材质、UV。把手允许在原包围盒外 12 毫米内修形。
4. 本轮保持墙体/楼梯/地板/门扇的结构顶点、开口、尺寸和门轴不变。
   需要改变建筑结构时，先交给开发同步碰撞，不能直接替换上线。
5. 导出 glTF 2.0 二进制 `.glb`，包含材质/UV/法线/自定义属性。
   不导出摄像机、灯光、动画；不要在导出时整体缩放、合并或改原点。
6. 将编辑的 GLB 交回，我会验证契约、接回游戏，并检查门、碰撞、
   室内灯光、子弹遮挡和帧率。验证失败时保留旧线上版，不静默上线。

地板高度 0.66 米、檐高 4.74 米、屋脊高 6.88 米。
